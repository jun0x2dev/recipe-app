# Expo CLI 터미널 단축키

`npx expo start` 또는 `npx expo run:ios` 실행 후 터미널에서 사용할 수 있는 단축키 목록이다.

## 기본 단축키

| 단축키    | 설명                                      |
| --------- | ----------------------------------------- |
| `r`       | 앱 리로드 (JavaScript 번들 새로 빌드)     |
| `j`       | React Native DevTools 디버거 열기         |
| `m`       | 개발 메뉴 토글 (시뮬레이터 내 메뉴)      |
| `shift+m` | 추가 개발 도구 목록 열기                  |
| `o`       | 프로젝트 코드를 에디터에서 열기           |
| `?`       | 사용 가능한 전체 명령어 보기              |
| `ctrl+c`  | 서버 종료                                 |

## 플랫폼 실행 (`npx expo start` 전용)

| 단축키 | 설명                          |
| ------ | ----------------------------- |
| `i`    | iOS 시뮬레이터에서 앱 열기    |
| `a`    | Android 에뮬레이터에서 앱 열기 |
| `w`    | 웹 브라우저에서 앱 열기        |

## 참고

- `npx expo run:ios`로 실행하면 `i`, `a`, `w` 단축키는 사용할 수 없다 (이미 iOS로 실행 중이므로).
- 시뮬레이터 콘솔 로그는 Metro 서버가 실행 중인 터미널에 출력된다.
- 로그가 안 보이면 `j`를 눌러 DevTools에서 확인한다.
- `npx expo start --clear`를 사용하면 Metro 번들러 캐시를 초기화한 뒤 시작한다.
