# Recipe App

나만의 레시피를 기록하고 공유하는 iOS 앱입니다.

요리 이름만 입력하거나 유튜브 링크를 붙여넣으면 AI가 레시피를 자동으로 작성해 줍니다.
직접 작성도 가능하며, 작성한 레시피를 공개해서 다른 사람과 나눌 수 있습니다.

> 사이드 프로젝트로 개발 중이며, iOS 앱스토어 출시를 목표로 하고 있습니다.

## 이런 걸 할 수 있어요

**레시피 기록**
- 3단계 위자드로 레시피 작성 (기본 정보 → 재료 → 조리 단계)
- 유튜브 링크를 붙여넣으면 AI가 레시피 초안을 추출
- 요리 이름만 입력해도 AI가 레시피를 자동 생성

**레시피 관리**
- 내 레시피 목록에서 검색·필터
- 공개/비공개 설정으로 원하는 레시피만 공유
- 카테고리 자동 분류

**요리할 때**
- 요리모드로 단계별 진행
- 다른 사람의 공개 레시피를 둘러보고 좋아요

**기타**
- 라이트/다크 모드 지원
- Google, Naver 소셜 로그인
